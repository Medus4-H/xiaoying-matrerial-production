# 账号身份与资料恢复记录

日期：2026-10-29。根据用户新增要求扩展原访客身份方案，见 [实施计划](./account-identity-plan.md)。单联系方式注册与绑定后续修正及最新验证见 [最新设计](./account-contact-design.md)。

- 实现邮箱及手机号注册、演示验证码、密码登录、账号切换和退出；有效访客注册时沿用原用户 ID，历史、素材和任务继续归原账号所有。
- 新增 V5 数据库迁移，将旧会话复制到独立会话表；账号使用加盐 PBKDF2 密码散列，账号与多个会话分离。
- 有资料的未注册访客登录其他账号时提示先注册；已注册账号切换时，前端暂停任务跟踪、取消和清理旧查询，身份未确定时要求重新查询。
- 容器验证：前端完整格式、lint、类型、测试及构建通过（Vitest 35 项、Node 测试 4 项）；Java 完整 verify 通过，含 MySQL 集成测试（20 项），覆盖账号注册、资料保留、过期恢复、两个账号的任务隔离、错误验证码、重复账号、生产环境禁用演示注册。测试中出现的模拟任务错误日志属于失败路径验证；Flyway 提示当前版本对 MySQL 8.4 的支持未正式验证。
- Compose 在保留原数据库和文件卷的情况下启动成功，浏览器检查了注册表单和演示说明。完整注册及切换行为由自动测试验证，未在浏览器手工创建真实账号。
- 已过期且没有凭据的旧匿名访客无法恢复；模拟验证码不验证联系方式，也没有真实发送、密码找回、登录限流或账号合并，不能用于生产。MySQL 和素材卷均需保留以恢复完整数据。
- 实际耗时未做独立精确计时，不以估算冒充实际值。
