# 账号身份与资料恢复实施计划

说明：本文件为初版身份方案的历史记录，单联系方式注册与绑定以 [最新设计](./account-contact-design.md) 为准。

目标：在保留现有用户 ID 和资料归属的前提下，引入邮箱、手机号、密码注册以及可恢复的账号登录。注册时将当前有效访客升级为账号；邮箱或手机号均可登录。模拟验证码仅供 demo 演示，非真实验证。

- 后端：新增账号和会话表及历史会话迁移；使用随机盐密码散列和独立 HttpOnly 会话；实现演示验证码、注册、登录与退出，校验来源、参数及唯一性。
- 防止遗失：有素材或任务的未注册访客在登录其他账号前必须先注册；注册不改用户 ID。已过期且无凭据的旧访客无法自动识别或恢复。
- 前端：身份弹窗提供注册、登录、退出和切换；模拟验证码可见且明确标注；过期后可重新登录。切换时取消旧请求、清理个人缓存并重建任务跟踪器。
- 验证：使用容器运行后端 MySQL 集成测试、前端组件测试及完整构建；检查访客升级、密码错误、两账号切换、记录隔离与会话过期后恢复。
- 限制：不提供真实验证码、密码找回、账号合并或生产认证；演示验证码在非 demo 配置关闭。
