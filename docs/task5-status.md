# Task 5：前端模板与访客身份记录

日期：2026-10-28。范围为前端基础、模板浏览及现有匿名访客身份交互；不改变身份找回方案，也不实现 Task 6、7 的上传、任务跟踪和历史页面。

## 已实现

- 共享 `IdentityProvider` 统一请求和维护访客身份，`useIdentity` 提供用户、状态、错误、重试、主动建立新身份及身份世代。多个消费者共享同一身份请求；只有 `/api/me` 返回 401 才会自动请求建立访客。
- 会话到期仍展示提示，由用户主动建立新访客；新身份建立前取消身份及个人素材、任务查询，成功后移除旧个人查询缓存并递增身份世代。上传及任务跟踪尚未接入，后续仍要验证完整跨身份隔离。
- 访客入口展示匿名身份说明弹窗，不展示虚构邮箱、密码、会员或账单。弹窗使用原生 dialog，支持 Escape 关闭并将焦点返回入口。
- 模板分类、列表及详情使用 Java 接口；已有加载、失败、空列表、详情 404 提示。列表采用暗色背景、图片卡片和分类筛选；小屏自动切换列数。
- 增加 Vitest、Testing Library、MSW 和 jsdom 的锁定依赖；原有 Node 测试保留。应用安装、格式、检查和测试均在容器中执行。

## 验证

- `docker compose -f compose.check.yml run --build --rm frontend-check`：格式、lint、TypeScript、4 项既有 Node 测试、6 项组件测试和生产构建通过。组件测试覆盖两消费者共享一次身份创建、身份请求失败不新建访客、弹窗关闭焦点、旧身份响应晚到、分类筛选/空状态、加载/错误/404。
- 独立 Compose 环境的浏览器实际验证：模板与封面加载，分类筛选，键盘进入模板卡片并打开详情；身份弹窗显示、Escape 关闭并恢复焦点。375 像素视口下首页导航、分类与两列模板可操作。
- 未验收后续上传、任务或历史交互；GitHub 托管 CI 尚未运行。设计中的里程碑提交未创建，因为当前目录尚未初始化 Git。
